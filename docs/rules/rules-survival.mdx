# 🌳 Правила режима «Выживание»

Режим выживания создан для спокойной игры, строительства, развития экономики и совместного творчества. 

:::info[Главное правило]
Относитесь к чужому труду с уважением. Сервер выживания не предназначен для разрушений и конфликтов.
:::

## 1. Игровой процесс и взаимодействие

<span id="1-1"className="anchor-fix"></span> [**1.1**](#1-1) Категорически запрещено любое **гриферство** (разрушение чужих построек, заливание лавой/водой, изменение ландшафта рядом с чужим приватом).

<span id="1-2"className="anchor-fix"></span> [**1.2**](#1-2) Запрещено воровство вещей из чужих сундуков, печей, воронок и других контейнеров, даже если они не запривачены.

<span id="1-3"className="anchor-fix"></span> [**1.3**](#1-3) Убийство игроков (PvP) разрешено только по обоюдному согласию или на специальных аренах. Запрещено убивать игроков с помощью ловушек, лавы или зелий вне PvP-зон.

<span id="1-4"className="anchor-fix"></span> [**1.4**](#1-4) Запрещено бессмысленное убийство мирных жителей (жителей деревень) и чужих прирученных животных.

## 2. Экономика и торговля

<span id="2-1"className="anchor-fix"></span> [**2.1**](#2-1) Запрещен обман при обмене ресурсами или торговле.

<span id="2-2"className="anchor-fix"></span> [**2.2**](#2-2) Запрещена продажа игровых ценностей за реальные деньги (RMT).

<span id="2-3"className="anchor-fix"></span> [**2.3**](#2-3) Запрещено использование багов и дюпов для незаконного обогащения. Обо всех найденных уязвимостях необходимо сообщать администрации.

## 3. Территории и постройки

<span id="3-1"className="anchor-fix"></span> [**3.1**](#3-1) Запрещено блокировать доступ к общественным порталам (в Незер, Энд) и важным игровым локациям.

<span id="3-2"className="anchor-fix"></span> [**3.2**](#3-2) Запрещено строить бессмысленные столбы (столбы в небо) и глубокие ямы, портящие внешний вид карты. Пожалуйста, убирайте за собой.

<span id="3-3"className="anchor-fix"></span> [**3.3**](#3-3) Запрещено приватить территории вплотную к чужим приватам без согласия их владельцев (минимальное расстояние — 2-3 чанка).

## 4. Технические ограничения

<span id="4-1"className="anchor-fix"></span> [**4.1**](#4-1) Запрещено создание механизмов, целенаправленно создающих нагрузку на сервер (лаг-машины).

<span id="4-2"className="anchor-fix"></span> [**4.2**](#4-2) Запрещено чрезмерное разведение сущностей (мобов, животных, вагонеток) в одном чанке, если это приводит к падению TPS. Администрация оставляет за собой право очистить переполненные фермы.
